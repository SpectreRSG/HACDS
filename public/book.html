How to make the PDF for the printer
  1. Use Google Chrome on a computer (not a phone).
  2. Click Print / Save as PDF. Set Destination to Save as PDF.
  3. Under More settings: turn Headers and footers OFF, turn Background graphics ON, Margins: Default.
  4. Upload the PDF as the interior file to a print-on-demand service (for example Lulu, Blurb or a local printer) and pick the same page size.
